Modifier les journées

Cet outil fonctionne sur votre appareil. Les contenus restent chiffrés lors de leur publication. L’accès au programme ne suffit pas pour publier : seul un compte GitHub autorisé peut le faire.

1. Ouvrir les contenus

Contenu introuvable

Le fichier chiffré content.enc.js n’est pas présent ou est vide. Aucun contenu ne sera remplacé.

Restaurez d’abord ce fichier depuis l’historique GitHub du dépôt EMMA, puis rechargez cette page.

2. Choisir le texte

Cliquez directement sur les phrases dans la zone ci-dessous et corrigez-les comme dans un document. Les encadrés et titres sont conservés. Utilisez les menus pour changer d’étape.

Évitez de supprimer les encadrés entiers. La mise en page et les liens sont conservés lors des corrections de texte simples.

3. Enregistrer / publier

Vérifiez vos corrections avant publication. Le bouton Télécharger crée une sauvegarde chiffrée, même si vous ne souhaitez pas publier immédiatement.

Publier directement sur GitHub (propriétaire uniquement)

Créez un jeton d’accès fin GitHub autorisé uniquement sur le dépôt nathanunifr/EMMA, avec l’autorisation Contents: Read and write. Le jeton n’est ni conservé ni envoyé ailleurs qu’à l’API GitHub.
