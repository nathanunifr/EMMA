EMMA – Programme complet (10 modules, 70 jours) · Démonstration web

LIEN
  https://nathanunifr.github.io/EMMA/emma/

CONTENU ET PARCOURS
  Le programme reprend les 70 journées des 10 modules du document
  « EMMA – Contenu complet du programme », V1.0 du 06.11.2026.
  Chaque journée est présentée en étapes successives :
  « Découvrir la suite », « Passer à l’exercice », etc.
  On peut revenir à l’étape précédente et reprendre la lecture plus tard.
  Les textes, exercices, liens et illustrations sont intégrés au
  fichier chiffré content.enc.js.

CONFIDENTIALITÉ
  Aucun questionnaire ou formulaire n’envoie de réponse à un serveur.
  Le code d’accès, la progression des jours, l’étape en cours et la
  taille de texte sont mémorisés dans le navigateur de l’appareil.
  Il n’y a ni compte ni synchronisation entre appareils.
  Les vidéos YouTube ne contactent YouTube qu’au lancement du lecteur.
  GitHub Pages peut conserver les journaux techniques usuels d’hébergement.

ACCÈS
  Le fichier content.enc.js est chiffré avec AES-GCM : le code n’est
  pas publié dans ce dépôt. Il faut demander le code d’accès à l’équipe.
  ATTENTION : la version complète a un nouveau code d’accès.
  L’ancien code des modules 1–2 ne permet plus d’ouvrir le programme.
  À la première ouverture après la mise à jour, saisir le nouveau code.

SUR IPHONE
  Ouvrir le lien dans Safari > Partager > Sur l’écran d’accueil.
  Si une ancienne version est affichée, rouvrir la page dans Safari
  et actualiser; si nécessaire, effacer les données de ce site.

TECHNIQUE
  index.html             Interface et déroulement des étapes
  content.enc.js         Contenu chiffré du programme complet
  sw.js                  Cache hors ligne de l’application
  manifest.webmanifest   Paramètres de l’installation mobile
  icons/                 Icônes

La plateforme ne remplace pas un suivi clinique ni l’évaluation
réglementaire et éthique du projet avant une utilisation en étude.
